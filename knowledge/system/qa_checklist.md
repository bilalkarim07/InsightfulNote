# Final QA Checklist

Evidence:
- Every material claim has evidence.
- Evidence IDs resolve.
- Quotes have provenance.
- Numbers/dates/locations are supported.
- Conflicts are preserved.

Neutrality:
- No unsupported political framing.
- No endorsement/persuasion.
- No loaded characterization as fact.
- Attribution and uncertainty are preserved.

Hallucination:
- No invented source, quote, statistic, tool call, or causal claim.

Style:
- Tone matches request.
- Hook is factual.
- No misleading clickbait.

Platform:
- Current platform constraints pass.
- CTA follows policy.
- Thread/video structure is valid.

Operations:
- Prompt version recorded.
- Model/provider recorded.
- Run ID recorded.
- Dry-run status correct.
- Duplicate publication check passed.
